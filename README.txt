NEW YORK STATE OF TRASH: exhibit version

To run it on this computer: double-click index.html. It opens in your web browser and works offline.
Keep index.html, data.js and the photos folder together in this folder.

To put it online: go to https://app.netlify.com/drop and drag this whole folder onto the page.

For the exhibit: open index.html in Chrome and press Cmd+Ctrl+F (Mac) or F11 (Windows) for full screen.
If nobody touches it for two minutes, it returns to the map by itself.

Quiz scores ("other players") are counted on this computer only.
